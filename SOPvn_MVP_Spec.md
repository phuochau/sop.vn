# SOP.vn — MVP Product Specification
**Version 1.0 | For Design Handoff**

---

## Core Value
Owner uploads a video → AI generates a Vietnamese step-by-step SOP → Export PDF or share via link.

**MVP scope:** Upload · Process · View SOP · Export PDF · Share Link

---

## Screen List

| # | Screen | Route |
|---|--------|-------|
| S1 | Landing Page | / |
| S2 | Upload Screen | /upload |
| S3 | Processing Screen | /processing/:id |
| S4 | SOP Result Screen | /sop/:id |
| S5 | PDF Export Preview | /sop/:id/export |
| S6 | Shared SOP View | /share/:token |
| S7 | Error Screen | /error |

> Auth and payment screens are out of scope for this spec.

---

## Screen Specifications

---

### S1 — Landing Page `/`

**Purpose:** Communicate value prop and drive users to upload.

**Elements:**
- Headline + sub-headline
- Primary CTA: "Upload Your Video" → /upload
- Secondary link: "See an example" → opens sample SOP modal
- 3 use case labels: Coffee recipes · Kitchen procedures · Spa protocols
- How it works: 3-step visual (Upload → AI extracts steps → Get SOP)
- Footer

**States:**
- Default
- Example modal open (overlay with sample SOP, 3–5 steps)

---

### S2 — Upload Screen `/upload`

**Purpose:** Accept the video file. No signup required.

**Elements:**
- Page title
- Upload zone (drag & drop + tap to browse)
  - Accepted: MP4, MOV, AVI, WEBM
  - Max size: 500MB
  - Max duration: 30 minutes
- Optional fields:
  - Video title (text input)
  - Category (dropdown): Coffee & Drinks / Food & Cooking / Spa & Beauty / Nail / Other
  - Language spoken (pre-selected: Vietnamese)
- CTA: "Generate SOP" — disabled until file selected
- Note: "Processing takes 1–3 minutes"

**States:**
- Empty — CTA disabled
- File selected — file name + size shown, CTA enabled
- Uploading — progress indicator, cancel option
- Upload complete — auto-navigate to S3
- Error: file too large
- Error: unsupported format

---

### S3 — Processing Screen `/processing/:id`

**Purpose:** Hold the user while AI processes the video.

**Elements:**
- 3-step progress indicator:
  - Step 1: "Uploading video..." (done on arrival)
  - Step 2: "Transcribing audio..." (active)
  - Step 3: "Generating SOP..." (pending)
- Estimated time: "Usually 1–3 minutes"
- Auto-redirect to S4 when complete (polls backend)

**States:**
- Transcribing (step 2 active)
- Generating (step 3 active)
- Complete → auto-redirect to S4
- Failed → show error state with retry CTA → /upload

---

### S4 — SOP Result Screen `/sop/:id`

**Purpose:** Display the generated SOP. Core value delivery screen.

**Elements:**
- SOP title
- Action buttons: "Export PDF" → S5 · "Share Link" (copies link to clipboard)
- Category badge + generation date
- Numbered step cards, each containing:
  - Step number
  - Step title
  - Step description (2–4 sentences)
- Feedback: "Was this SOP accurate?" → thumbs up / thumbs down
- "Generate Another SOP" → /upload

**States:**
- Loaded — full SOP displayed
- Empty (0 steps) — message: "We couldn't extract steps. Try a video where you narrate each action." + retry CTA

---

### S5 — PDF Export Preview `/sop/:id/export`

**Purpose:** Preview and download the SOP as a printable A4 PDF.

**Elements:**
- A4-proportioned preview of the PDF layout:
  - Header: SOP title + category + date
  - Body: numbered steps
  - Footer: "Generated by SOP.vn"
- CTA: "Download PDF"
- Back link: "Back to SOP"

**States:**
- Loading — generating PDF server-side
- Ready — preview shown, download enabled
- Error — retry button

---

### S6 — Shared SOP View `/share/:token`

**Purpose:** Read-only SOP view for anyone with the link. No account needed.

**Elements:**
- Same step content as S4
- Top banner: "Shared SOP — view only"
- "Download PDF" button (recipients can print)
- Footer: "Create your own SOP at SOP.vn"

**No:** Edit actions · Feedback · Generate another

**States:**
- Valid token — SOP displayed
- Invalid / expired token — "This link is no longer available" + link to homepage

---

### S7 — Error Screen `/error`

**Purpose:** Catch-all for unexpected failures.

**Elements:**
- Error icon
- Headline: "Something went wrong"
- Context-aware message (see table below)
- CTA: "Try Again" → /upload
- Secondary: "Contact Support" → email

**Error messages:**

| Error | Message |
|-------|---------|
| Video too short (<10s) | "Video is too short. Please upload at least 10 seconds." |
| Unsupported format | "File format not supported. Please use MP4, MOV, or WEBM." |
| Silent / noisy audio | "We couldn't hear clear speech. Try a video where you narrate each step." |
| AI processing failed | "Something went wrong on our end. Please try again." |
| File too large | "File exceeds 500MB. Please compress your video and try again." |

## Key User Flows

### Happy Path

| Step | User Action | Screen |
|------|-------------|--------|
| 1 | Arrives on homepage | S1 |
| 2 | Taps "Upload Your Video" | S1 → S2 |
| 3 | Selects video file | S2 |
| 4 | Optionally fills title & category | S2 |
| 5 | Taps "Generate SOP" | S2 → S3 |
| 6 | Waits 1–3 minutes | S3 |
| 7 | Auto-redirected to SOP | S3 → S4 |
| 8 | Reviews steps | S4 |
| 9 | Taps "Share Link" | S4 |
| 10 | Sends link via Zalo to employee | Outside app |
| 11 | Employee views read-only SOP | S6 |

### Export PDF Flow

| Step | User Action | Screen |
|------|-------------|--------|
| 1 | Taps "Export PDF" on SOP screen | S4 → S5 |
| 2 | Previews A4 layout | S5 |
| 3 | Taps "Download PDF" | S5 |
| 4 | Prints and pins in kitchen / spa | Outside app |

### Error Recovery Flow

| Step | Trigger | Screen |
|------|---------|--------|
| 1 | Audio silent or noisy | S3 → S7 |
| 2 | User taps "Try Again" | S7 → S2 |
| 3 | Uploads a different video | S2 → normal flow |
